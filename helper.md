# Helper.md: Руководство и журнал реализации инструмента генерации запросов 1С (BSL/СКД) с ИИ и MCP-сервером

Данный файл предназначен для параллельной непрерывной фиксации шагов разработки, контроля стандартов качества BSL/СКД запросов и отслеживания статусов выполнения проекта.

---

## 1. Архитектурный обзор проекта

Система обеспечивает перевод запроса клиента в свободной форме в BSL. Порядок: клиент → модель → MCP (search_metadata, затем get_metadata_structure) → текст BSL. Хост не ищет метаданные до модели и не исполняет запрос в базе. Все основные компоненты инструмента (MCP-сервер метаданных, веб-панель управления и сервис взаимодействия с ИИ) контейнеризированы с помощью **Docker** для простоты развертывания, изолированности и масштабируемости.
